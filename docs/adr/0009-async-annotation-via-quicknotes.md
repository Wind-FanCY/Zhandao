# 标注是异步两段式的，经由速记

**标注**产生于实践之后——你在写代码、看报错时突然理解了几周前收录的某份**材料**。那一刻你在编辑器或终端里，不在知识库里。而**收录**有 `Ctrl+D` 这个现成的肌肉记忆，标注没有任何对应物。

因此标注拆成两段：当场只做最轻的动作——在终端敲一行命令记下那句话，成为一条**速记**；归属到哪份**材料**、以及由 agent 搜索并确认**关联**（ADR-0001），全部推迟到之后打开 Web 界面批量处理。

这与 ADR-0002 的结构完全相同，而 ADR-0002 已被实测验证成立：把「判定值得留」与「入库」拆开，轻动作才可能真的发生。

## Considered Options

- **Web 界面内直接写**：要求在顿悟的瞬间打开应用、搜索、点击。那一刻本人正在调 bug，转化率接近零，库将永远没有**标注**，也就永远没有价值。已否决。
- **全局快捷键 / 菜单栏工具**：摩擦最低，但需要 macOS 原生小工具或系统级快捷键配置，是一条独立技术线（与否决浏览器扩展同理），对学习目标零贡献。
- **仅命令行同步完成**：`zd note` 当场还要求选定宿主**材料**——而 Q10 已定**标注**必须有宿主，当场找宿主就是给最该轻的动作加最重的负担。
- **异步两段式**（已选）：轻动作用命令行，重动作在 Web 批量完成。

## Consequences

- 引入**速记**这一新状态：已记下、尚未归属，**它还不是标注**——与「**收件箱**条目还不是**材料**」完全平行。
- **速记会堆积**，这是与收件箱堆积同一个失效模式（ADR-0002 已点名）。必须同样持续盯着。
- agent 只在批量归属时介入（搜索候选宿主、提议**关联**），不在记录速记时介入——那一刻不能有任何延迟。
- 记录入口是命令行，因此本人敲下速记时**服务不需要在运行**：速记只是往数据仓库里追加一行。这与 ADR-0002 的「收录不依赖服务在线」保持一致。
