# 预练自成一条链路：材料里现成的问题不进复习调度

**预练**（就一份**材料**里的**练题**逐道作答、自评会不会）与闭环里的**出题 / 答题**是**两条链路，共享零个数据结构**：

```
闭环   标注 ──→ 题目（即时生成，不留存） ──→ 答题记录 ──→ 决定这条标注何时重推
预练   材料正文 ──→ 练题（提取，可重建，住 .cache/） ──→ 练题记录 ──→ 决定这道练题下轮出不出
```

三条硬线：**练题**不是**题目**；**练题记录**不是**答题记录**；**预练**不进推送池、不改**孤岛**判据。

## 为什么不合并

两套东西看起来高度重复（都是「出一个问题、记一次结果」），合并的诱惑很大。不合并的理由是**答错的含义不同**：

```
答错一道题目    我自己写下的那条理解衰减了        ← ADR-0004 要的信号
答错一道练题    别人文章里的一个事实我没记住      ← 对上面那个信号是噪音
```

ADR-0004 把调度信号定为「依据本人自己的表现」，而那个「表现」指的是**标注**（本人写下的理解）有没有拿住。**练题**考的是**材料**内容，它产生的记录混进去，会让**标注**的重推顺序被「网络协议细节背没背下来」带跑——而那不是这个库要解决的问题。

## 为什么预练不清孤岛

**孤岛**按增量定义（没有**标注**指向、未发出过**标注**、未**留档**）。**预练**过但没写**标注**的**材料**仍然是**孤岛**。

理由不是洁癖，是排水口。`CONTEXT.md` 已记下**留档**的已知代价——「『什么都不写』的唯一出口，一定会被滥用（累的时候一路点留档最省力），那样数字好看而库还是没消化」。**预练**比**留档**更像在干活，作为排水口**更有吸引力、因而更危险**：刷一晚**图解网络**能把 41 篇集体清出**孤岛**，而产出的**标注**是 0 条。而推送链路唯一的使命就是攒**标注**，池子被抽干它当场哑掉。

**预练之后的两种情况，已有的三个终态都覆盖了，不需要开第四个**：

```
全会           → 留档（「读完后判定无可标注、但仍值得留在库中」，正是它的定义）
发现想错了     → 标注（「我一直以为 X，其实是 Y」——这是个人理解，不是抄答案）
```

## 为什么练题由模型提取，而「提取而非生成」要做成机械不变量

纯机械提取实测覆盖 21/49 份**材料**、98 道题，**但失效正好落在靶心**：三篇明确为了刷题而收的**材料**合计只提出 3 道。

```
Promise 45 道      0 道   题的形态是 #### 1.1 题目一 + 代码块，标题只是编号标签
手撕代码篇         0 道   ## 防抖函数 / ## 深拷贝，名词短语
性能优化篇         3 道   27 个标题里 24 个是知识点名（图片压缩、精灵图）
```

要机械拿到 Promise 那 45 道，只能写 `^#### \d+\.\d+ 题目` 这类规则——**那正是 CLAUDE.md 为 `unwrapCodeWrappers` 明令禁止的「给某个站点生成器打补丁」**。

改用模型之后，「提取而非生成」不能只靠 prompt 那句话维持：**每道练题必须携带一个能在正文里定位到的锚点，定位不上的整条丢弃。** 这把一句主张换成了可执行的检查——「答案就在原文里」从声明变成性质。

成本形状与两处已接受的决定逐字相同：调用次数 = **材料数**（不是查询次数），**材料**正文不可改 → 提取结果是正文的**纯函数** → 永久缓存进 `.cache/`，删了重跑（ADR-0003）。

## Consequences

- **孤岛数不会因为预练而变好看。** 它本来就长期难看（几十篇**材料**、个位数**标注**），预练不改善这个数字。这是设计意图，不是缺陷。
- **两套近似的术语并存，读到的人一定会问「为什么不合一」。** 这就是本 ADR 存在的理由。`CONTEXT.md` 里**练题**与**练题记录**的 `_Avoid_` 各自点名了对方。
- **练题记录是不可再生的真实数据**，住 `data/`、追加式；**练题清单是正文的纯函数**，住 `.cache/`、可删。两者不能放在一起，也不能互相重建。
- **接受一个洞：预练完全依赖本人想起来要练。** 「你想不起来的东西不会去搜，主动搜索是最弱的一档召回」是本项目开头就写下的约束，而**预练**恰好是那一档。面试前有外部压力会想起来，平时不会。所以它不承担「让库不死」的责任——那件事由推送负责。**若实际发现平时也需要被推着练，本条需重议**，届时必须重新论证「两个队列共用一个推送位」为什么不算污染。
- **练题提取是第三个模型调用点**，跨过了 CLAUDE.md 写下的「调用点长到三个以上、能看出共同形状时再抽 `interface ModelProvider`」那道门槛。本 ADR 不做那个抽象，只记下门槛已跨过。
- **不调模型批改作答。** 判断自由文本与原文的语义等价是这堆里最难的模型任务，判错直接污染**预练**唯一产出的那条记录；而它省下的只是「你自己扫一眼原文」。**这是纯增量**：将来要加，只是换掉会/不会那一位的来源，数据模型不动。
- **作答文本不留存**，故「上次我是怎么答的」查不回来。判断是回看旧答案的价值低于它在 `data/` 里堆起的一层无增量文字——**这是推测，没有数据**。
